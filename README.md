# Galactivos Universe — web

Versión web de Galactivos Universe publicada con GitHub Pages:
https://losgalactivos-pixel.github.io/galactivos/

Funciona en **modo local**: todo se guarda en el navegador de cada persona (planificación, ideas, guiones, miniaturas y calendarios). Para conectar cuentas de redes, publicar y responder comentarios hace falta ejecutar el servidor de Galactivos Universe.
